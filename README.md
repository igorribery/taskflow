# taskflow

Monorepo inicial do projeto TaskFlow com estrutura separada em:

- `aplicacoes/backend`: API RESTful em Node.js + NestJS + Prisma + PostgreSQL + Redis.
- `aplicacoes/frontend`: Next.js + React + TypeScript + Tailwind + bibliotecas de UI e estado.

## Estrutura inicial

```bash
aplicacoes/
  backend/
  frontend/
```
